# Payfast ID — Dokumentasi Produk

Paket dokumen untuk pembuatan website company profile **Payfast ID** (Next.js 16.x berbasis JavaScript/JSX, Tailwind CSS v4, warna utama `#ee4d2d`).

| Dokumen | Isi | Untuk siapa |
|---|---|---|
| [PRD.md](./PRD.md) | Tujuan, scope, persona, requirement per halaman, NFR, risiko, acceptance criteria | Client, PM, semua tim |
| [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md) | Palet warna, tipografi, komponen UI, token Tailwind v4, aturan kontras, daftar aset | Designer, frontend |
| [CONTENT_SPEC.md](./CONTENT_SPEC.md) | Isi/teks dummy per halaman & section, struktur data konten, checklist ganti konten | Client, frontend, content |
| [TECH_SPEC.md](./TECH_SPEC.md) | Stack, struktur folder, rendering, SEO, form, security, deploy | Developer |
| [TASKS.md](./TASKS.md) | Milestone & checklist kerja, estimasi | PM, developer |

## Urutan baca yang disarankan
1. **PRD** → sepakati scope dan jawab pertanyaan terbuka (§6).
2. **DESIGN_SYSTEM** + **CONTENT_SPEC** → acuan tampilan dan isi.
3. **TECH_SPEC** → mulai implementasi.
4. **TASKS** → lacak progres.
